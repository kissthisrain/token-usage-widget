# v0.1.3 发布说明

> 修复 **token 用量统计与客户端界面不一致** 的问题：统计口径统一为与 ZCode/Codex/DSH 界面一致的原始消耗量，并消除权威数据回填"只增不减"导致的永久虚高。

## 🛡️ 修复

- **统计口径与各客户端界面对齐**
  - token 消耗量按界面同口径累计（`totalTokens`，含缓存命中读取），ZCode / Codex / DSH 三条解析路径统一出口、固定注释，杜绝两套解析逻辑口径漂移

- **修复 sqlite 权威回填"只增不减"的虚高问题**
  - 旧逻辑按天按模型取 max 合并，一旦实时增量侧累计出虚高值，权威数据源（`db.sqlite`）每 5 分钟回填也永远无法收敛
  - 改为：sqlite 权威数据**按天整体替换** + 从近期记录自动回收 sqlite 尚未落库的最新请求（幂等收敛，不丢最新数据）
  - 附带清理 watcher 中重复的 ZCode 解析实现，并新增 ZCode 解析单元测试防止口径回归

## ⚠️ 已知限制

- OpenAI 用量接口需组织管理员 Key（普通 Key 返回 403）
- 「本地记录」与「OpenAI 官方」同时统计同一提供商时会重复计数，建议二选一
- OpenCode Go 官方额度依赖登录 Cookie，会话过期后需重新获取
