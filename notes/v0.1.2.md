# v0.1.2 发布说明

> 修复 **OpenCode Go 官方月剩余用量偶发无法显示**的问题，重绘应用与托盘图标。

## ✨ 新功能

- **重绘应用 logo 与托盘图标**
  - 新图案：深色玻璃圆角块 + 环形配额进度（青→绿主弧代表剩余、紫余弧代表已用，呼应精简视图的 conic 环形）+ 中央 token 火花 + 底部三色用量柱
  - 配色对齐主题（teal `#2dd4bf` / violet `#8b5cf6` / amber `#fb923c`），4×4 超采样抗锯齿，边缘平滑
  - 生成脚本（`npm run icon`）一键输出主图标源（1024）/ 托盘图（32 / 16）/ 预览图，exe 内嵌图标与托盘图标同步更新

## 🛡️ 修复

- **修复 OpenCode Go 官方月剩余用量无法显示**


## ⚠️ 已知限制

- OpenAI 用量接口需组织管理员 Key（普通 Key 返回 403）
- 「本地记录」与「OpenAI 官方」同时统计同一提供商时会重复计数，建议二选一
- OpenCode Go 官方额度依赖登录 Cookie，会话过期后需重新获取
- dsh 的 token 总量含缓存重放（与 ZCode 口径不同），对比跨源数据时请注意
