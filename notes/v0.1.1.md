# v0.1.1 发布说明

> 新增 **DeepSeek Harness（DSH）** 数据源、模型列表品牌 Logo，并修复一批数据准确性与安全问题。

## ✨ 新功能

- **新增第 6 类数据源：DeepSeek Harness（DSH）**
  - 自动探测 `~/.dsh/sessions`，解析 zstd 压缩会话日志（`session.jsonl.zstd`）中的 `assistant/message` 用量事件
  - 实时监听：会话过程中新增请求毫秒级推送到小组件
  - 重启不重复统计（每文件事件计数去重，截断/重写自动整源重建）
  - **统计口径**：`total = input + output + cacheReadTokens`。dsh 每次请求都会重放整段会话缓存上下文（缓存 token 约为新 token 的 100 倍），按"实际处理/计费 token"统计才反映真实用量；该口径与 ZCode（不含缓存）不同，为 dsh 专属
- **模型列表展示品牌 Logo**：真实 SVG 图标（离线内联），支持 OpenAI / Claude / DeepSeek / Gemini / GLM / Qwen / MiniMax / 混元 / MiMo / OpenCode，Kimi / Grok / Codex / ZCode 用手绘近似，未识别回退彩色字形

## 🛡️ 数据准确性与安全修复

- **修复 token 双倍计数**
  - 自愈/文件截断重建时清空该源全部数据再重扫，修复 34 天前历史被重复累加
  - 新增文件截断/重写检测（偏移 > 文件大小 → 整源重建），防整文件重加
  - 超大文件标记已消费，避免反复触发自愈
- **修复凭据跨域转发风险**：HTTP 重定向仅跟随同主机且不降级 https，防止 `Authorization` / `Cookie` 被转发到第三方域名
- **修复代理 SSE 流式用量漏记**：跨 chunk 行缓冲重组半截 `data:` 行；按响应 content-type 判断流式
- **修复 sqlite 回填抹掉实时增量**：按模型取最大值合并，权威数据与实时日志双向不丢
- **未计费配额显示 `~` 估算标记**：未知模型/未配置价目时明确提示为估算值
- 精简视图优先展示官方额度，官方失效时自动回退估算（不再展示过期数据）
- 配置/历史文件损坏时先备份再回退默认，避免静默覆盖丢失 API Key 等凭据
- 窗口移动持久化 500ms 防抖，减少高频写盘
- 文件扫描迁移到阻塞线程池，界面不再被大目录扫描卡顿

## 🖥️ 其他改进

- 冒烟测试（`--smoke`）在探测异常时返回非零退出码，便于 CI 感知
- `cargo clippy` 保持 0 警告

## ⚠️ 已知限制

- OpenAI 用量接口需组织管理员 Key（普通 Key 返回 403）
- 「本地记录」与「OpenAI 官方」同时统计同一提供商时会重复计数，建议二选一
- OpenCode Go 官方额度依赖登录 Cookie，会话过期后需重新获取
- dsh 的 token 总量含缓存重放（与 ZCode 口径不同），对比跨源数据时请注意
