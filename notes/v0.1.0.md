# v0.1.0 发布说明

> 首版正式发布：从 Electron 版完全重写为 **Rust + Tauri 2**，启动更快、占用更低、数据管道更稳定。

## ✨ 核心功能

- **实时用量监控**：TOTAL TOKENS 大数字带滚动动画，每次 AI 请求完成立即跳动更新
- **费用统计**：总费用（USD），支持按模型价目表折算
- **额度剩余**：各数据源剩余百分比进度条 + 重置倒计时
- **模型明细**：按模型分组的 token 消耗与占比进度条
- **趋势图表**：面积折线图，自动标注峰值
- **活动热力图**：GitHub 风格热力图 + 活跃天数
- **时间筛选**：DAY / MONTH / TOTAL 三档切换

## 🔌 数据源（5 类）

| 数据源 | 说明 |
|---|---|
| **本地记录**（自动探测，零配置） | 实时监听 ZCode 与 Codex 会话日志，毫秒级推送；历史用量自动从 ZCode SQLite 回填，开箱即有 30 天数据 |
| **OpenAI 官方** | 用量 API 直连，支持回填 90 天历史（需组织管理员 Key） |
| **兼容中转站** | 自动探测常见余额接口（billing / balance / auth-key / one-api 四种风格），支持自定义 URL 与字段映射 |
| **OpenCode Go 本地代理** | 本地 SSE 流式代理，转发请求并记录本机每次用量，对照官方限额估算剩余 |
| **OpenCode Go 官方额度** | Cookie 抓取官方控制台数据（**权威**，含所有设备）：5 小时 $12 / 每周 $30 / 每月 $60 |

## 🖥️ 桌面体验

- 玻璃拟态深色风格，无边框半透明（Win11 亚克力毛玻璃），置顶悬浮
- 跨显示器拖拽支持，混合 DPI 下尺寸稳定，窗口位置自动记忆
- 精简模式：托盘切换只显示剩余用量的迷你视图
- 系统托盘：左键单击显示/隐藏，右键菜单（显示/隐藏、精简模式、设置、退出）
- 全局热键 `Ctrl+Alt+U`，设置中可自定义
- 开机自启（可选）
- 单实例运行，重复启动自动唤起已有窗口

## 🛠️ 数据与设置

- 数据源「测试连接」、本机工具自动探测（ZCode / Codex / OpenCode CLI）
- 数据导出为 JSON、一键清空数据
- 冒烟测试模式：`--smoke` 无界面验证数据管道
- 所有数据仅存本机（`%APPDATA%/token-usage-widget/`），与旧 Electron 版数据兼容、无缝迁移

## 📦 构建与分发

- GitHub Actions：打 `v*` tag 自动构建绿色版 exe，并自动创建 GitHub Release（附本发布说明；缺失时自动汇总提交标题兜底）
- 绿色版免安装，双击即用（依赖系统自带 WebView2）

## ⚠️ 已知限制

- OpenAI 用量接口需组织管理员 Key（普通 Key 返回 403）
- 「本地记录」与「OpenAI 官方」同时统计同一提供商时会重复计数，建议二选一
- OpenCode Go 官方额度依赖登录 Cookie，会话过期后需重新获取
